## Long description

```markdown
Vectorizer turns a PNG or JPG into a clean SVG, then into files you can actually cut or print. It runs in your browser and nothing is uploaded.

## Free, forever

- Unlimited PNG, JPG and WebP to SVG
- Background removal
- Download the SVG or copy its code
- Preview every 3D mode

## Pro: maker exports

These use the output width you set, in millimetres, so the file comes out the real size.

- **Sized SVG with each colour on its own named layer**, for Inkscape, Cricut Design Space and LightBurn
- **One SVG per colour** (.zip)
- **DXF R12 for laser cutters:** closed polylines, one layer per colour
- **Batch convert:** a folder of images to sized SVG + DXF in one zip

## Pro: print it in 3D

STL preview is free; download is Pro.

| Mode | What you get |
|---|---|
| Cookie cutter | Thin cutting wall and a flange that prints on the bed. Follows the outside outline, mirrored because it's used flange-up. |
| Stamp | Base plate and raised design. Base follows the outline, or is a rounded rectangle or circle. Mirrored so the impression reads correctly. |
| Stencil | Flat plate with the design cut through. Bridges are added automatically so the centres of O, A and B don't fall out. |
| Multi-colour plaque | Base plus one STL per colour, as a zip, for an AMS. Optional magnet pocket underneath for fridge magnets. |

Every mode exports watertight meshes, with zero open or non-manifold edges.

## Who it's for

Cricut and laser users who need a logo at an exact size, bakers and cookie makers turning drawings into cutters, and 3D printing makers who want stamps, stencils and colour plaques without opening CAD.
```
