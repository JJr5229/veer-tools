## How to use these

- **Copy what's in the code blocks.** Titles, tags, descriptions, personalization text and receipt emails are in grey code blocks so they paste without Markdown formatting. Everything outside the blocks is a note for you.
- **Fill in every `[square bracket]` first.** Those are things only you know: your filament colours, USB cable length, whether a wall plug is included, processing times, the hosted tool URL, license activation limits. Search each file for `[` before publishing.
- **Etsy tags:** paste the comma-separated line into the tag box; it splits into 13 tags. The table under it lists each tag's length (all ≤20).
- **Etsy photos:** take the real photos in each shot list before publishing. Etsy expects photos to show the actual item; tool previews are supporting images only.
- **Etsy rules:** buyers send photos and logos through Etsy Messages after checkout. Never ask a buyer to order or pay off Etsy, and don't add links to outside shops (including Veer) in Etsy listings or messages.
- **Selling prints:** the Etsy light boxes and NFC items need the Commercial licenses for Light Box Studio and NFC Studio. Prices are suggestions; adjust after you weigh your first prints and see real fees and shipping.
