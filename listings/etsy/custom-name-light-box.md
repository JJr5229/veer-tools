## FAQ

**Can I see it before you print?**
Yes. Write PROOF in the personalization box and we'll send a lit preview through Etsy Messages, usually within one business day.

**How long a name fits?**
The 180 mm name sign suits names up to about 10–12 letters. For longer names, two names or a name with a second line, choose Wide (220 mm).

**Does it need batteries?**
No. It runs from USB: any phone charger, laptop or USB wall plug. [If you offer it: a battery puck light can be fitted instead; ask us.]

**Is it safe in a nursery?**
The LED strip is 5 V and runs cool. As with any corded light, keep the cable out of reach of babies and young children and place or mount the box securely. It's a decoration, not a toy.

**Can I hang it on the wall?**
Yes. There are two keyhole slots on the back for small screws or nails.

**Can you match a nursery colour?**
Often, yes. Tell us the colour in the personalization box and we'll message you if we need to suggest the closest filament we have.

**What if something arrives damaged?**
Send us a photo through Etsy Messages and we'll make it right.

## Owner workflow

1. Each morning, open the day's orders. Copy each name (and line 2) into a list, grouped by size and font.
2. Open **Light Box Studio**, pick the size preset (Name sign 180 × 80, Wide 220 × 90 or Square 120 × 120), set depth 40 mm, choose the font, and set frame/front colours.
3. Paste the names into **Batch names** (one per line). Export the STL set: one shared frame and back, plus one front per name, and a **proof PNG per name**.
4. For orders that asked for a proof, send the proof PNG through Etsy Messages. Wait for "approved".
5. Print frames and back panels in batches (same for every order of that size). Print fronts in white with the letter colour via AMS.
6. Fit the LED strip around the inside walls, run the cable through the back hole, press the back in. Plug in and check for even light before packing.
7. Package with the order note and ship. Mark the order shipped with tracking.
