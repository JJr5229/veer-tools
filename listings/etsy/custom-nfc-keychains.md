## FAQ

**Will this work with my Google reviews?**
Yes. Send us your review link (from your Google Business Profile → "Ask for reviews") and we'll program it. It works with any review page that has a web link.

**Do customers need an app?**
No. Modern iPhones and Android phones read NFC out of the box.

**Can I change the link later?**
Yes, unless you ask us to lock it. Use a free NFC app to rewrite it.

**Can each keychain have a different link?**
Message us before ordering with how many different links you need.

**How tough are they?**
They're 3 mm thick solid PLA and fine on a keyring day to day. Like any plastic keychain, they'll pick up scuffs over time. Avoid leaving them in a hot car.

**What if one doesn't scan?**
We tap-test each keychain before it ships. If one doesn't work when it arrives, message us and we'll replace it.

## Owner workflow

1. Save the logo from Etsy Messages. Copy the link and body colour from the personalization field.
2. Open **NFC Studio** (Commercial license). Choose the keychain preset that matches the buyer's shape: **Keychain** 45 × 28 × 3 (22 mm tag), **Pill keychain** 50 × 25 × 3 (20 mm tag), **Round keychain** 35 × 3 (22 mm tag) or **Square keytag** 38 × 38 × 3 (25 mm tag). Keyring hole on, 4 mm for a split ring.
3. Drop in the logo, set colours, keep the tag sealed. Check the warning bar if the cavity shrinks around the hole.
4. Send the front preview as a proof through Etsy Messages.
5. After approval, export the STL set, import into Bambu Studio as one multi-part object, fill a plate. Add the pause at the reported Z height, drop in tags, resume.
6. Program each with NFC Tools (Write → URL). Lock only if asked. Tap-test with iPhone and Android. Fit split rings.
7. Pack, ship, mark shipped.
