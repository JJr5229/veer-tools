## FAQ

**What file should I send?**
PNG with a transparent background, SVG or PDF is best. A clear JPG works. Send it through Etsy Messages after checkout.

**Can you match my brand colours exactly?**
We match to the closest filament we stock and show you in the preview. Light passing through coloured filament tints it a little, which the preview also shows.

**My logo has a gradient / photo / very fine lines.**
We'll simplify it into solid colour areas. The preview shows the result before anything is printed.

**Can I order more than one?**
Yes. Increase the quantity at checkout and they'll all be made from the same approved preview.

**Will it work on a wall?**
Yes, two keyhole slots on the back take small screws.

**Can I use someone else's logo?**
Only if you own it or have permission. We don't make signs with other companies' trademarks.

## Owner workflow

1. Save the buyer's logo from Etsy Messages to the order folder.
2. Open **Light Box Studio** (Pro). Pick the preset (Square 120 × 120, Name sign 180 × 80 or Wide 220 × 90), depth 40 mm. Drop in the logo; set **Image colours** (1–3) and tick **Drop the background colour**. Add line 1 / line 2 text if ordered.
3. Set frame and logo colours to match your filament. Export the **proof PNG** and send it through Etsy Messages.
4. After approval, export the STL set (one STL per colour). Print the front face-down via AMS; batch several fronts on one plate to save purge.
5. Print frame and back in the chosen colour. Fit the LED strip, run the cable through the back, press the back in, test.
6. Keep the approved project file in case the client reorders.

Note: selling these prints requires the **Light Box Studio Commercial** license.
